# 学习内容来源

## 内置词汇

- P0 的 8 词：`starterWords`，项目原创释义与例句。
- `app/src/main/assets/academic_words.csv`：本项目编写的学术通用词汇练习，中文释义与英文例句原创，适用项目 LICENSE。未复制考试真题、第三方词典或商业词库。
- 英语单词本身为通用语言事实；这里不是官方六级大纲词表，不声称覆盖六级全部词汇。新增词表仍需使用者检验学习适用性。
- 内置新增内容只以 IGNORE 方式补入；不会重置已存在的释义、来源或学习进度。

## 用户导入

在单词页“导入我的词库”中填写来源与授权说明，确认有权使用，再选择 UTF-8 CSV/JSON 文件。来源说明与每个新词一起保存在数据库中，在词库浏览处可见。应用不能代替用户验证第三方授权。

CSV 必须使用以下表头；有逗号、双引号或换行的字段须正确引用：

```csv
word,meaning,example
allocate,分配,We allocate time for revision.
```

JSON 必须是对象数组，三个字段都为文本，`example` 可为空：

```json
[{"word":"allocate","meaning":"分配","example":"We allocate time for revision."}]
```

规则：2 MiB / 10000 条上限；单词转小写并去首尾空白；支持英文单词、空格/连字符/单引号连接的短语；释义非空。文件内部重复或任一格式错误会拒绝整份文件；与已有词库重复则跳过，保留原有释义、来源、调度和学习日志。无任何网络上传。
