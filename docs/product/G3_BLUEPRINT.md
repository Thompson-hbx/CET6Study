## G4 决策修订（2026-10-18，历史背景）

用户后续明确修改阅读方式：在真实纸质试卷上完成后，将答案录入 App 核对，再逐步提示如何在原题找到正确答案。此要求优先于原 G4 的 App 内直接四选一做题方向。用户进一步明确：录入按篇章分成两组，每组均为1—5，直接填写五个选项，不要求输入原题号；原题号仅内部追溯来源。整套选卷为主，分篇录入为辅；核对先给正误，题干线索 → 原文段落 → 证据句 → 选项与参考逐层揭示。AI 只补充当前一题 / 当前一层，不默认直接给完整解析。

以下决策替代 G3 的默认粘贴入口、突出旧单词模块和保留 TTS 代码的方向；下文 G3 原文保留为历史。

- 产品围绕真实考次 → 套次 → 仔细阅读 / 写作 / 翻译展开。2023—2026 已举行考次按真实日期归档，含 2023-03-12 加考，不预置 2026-12 真题。
- 未取得正文再分发授权时只内置可追溯目录，不将公开网页等同授权，不编造真题；个人合法资料由用户本地导入并校对。APK 仅内置 24 套目录。2026-10-18 本机个人包在模拟器已导入 24 条，14 套有来源键可核对、10 套待校对；私有资源与 APK / Git 分离，原创测试样本单独标识。
- 主导航为题库、训练、复盘、我的。默认题库；连接与模型、备份、旧版学习功能均放入二级入口。自定义粘贴练习保留。
- Paper & Ink 采用纸张暖灰、墨色、低饱和绿及线性目录；阅读采用纸上独立完成 → 录入答案 → 有来源核对 → 分层定位提示，正文仅作对照；写译以连续编辑空间为主。少量 Material 原生组件保留，避免多层卡片。
- 删除旧 TTS 播放及生命周期代码、入口和 Service 查询；保留单词、音标、FSRS 历史和所有数据表。
- 内容包与学习记录分开，版本化 JSON 管内容，Room v7 管快照和作答。修订不改历史，重复导入不增套，冲突显式拒绝。原 OAuth / SSE / Keystore / 模型选择协议不变。
- PDF / DOCX 通过本地文本提取、人工分区与校对转 JSON；扫描件不猜内容，暂不自动 OCR。格式、备份边界见 `docs/EXAM_IMPORT.md`。实施与验证状态只在 `docs/TODO.md` 维护。

## 一句话目标
在安卓手机上把六级阅读、写作和翻译变成 **练习 → 有依据的 AI 反馈 → 错因归档 → 针对性复习** 的闭环；不再开发低配版「不背单词」或「百词斩」。
## 为什么转向
- 真机的 Android TTS 发音机械，改善到成熟商业背词 App 的质量需要语音素材、授权和额外维护投入。
- 词库、发音、例句、复习调度、打卡等功能与成熟背词产品高度重叠，现有实现又不够完善。
- 真正有差异化的资产是已验证的 ChatGPT OAuth / Responses API 调用能力，以及根据个人错因生成讲解和训练的可能性。

## G3.0 MVP 必需功能
### 1. 阅读 AI 教练（最高优先级）
- 从剪贴板粘贴文本，后续支持系统分享导入；配套可合法使用的练习题和原文。
- 作答、判题、标注原文证据；AI 解释正确选项及干扰项，拆解长难句和逻辑关系。
- 对证据不足或模型不确定的解析明确标记；保留追问、收藏难句和错因分类。
- 将错因写入 Room，并从错因生成针对性微练习。
### 2. 作文与翻译教练
- 支持作文或中译英文本输入及题目管理。
- AI 返回逐句错误、原因、修订示例与整体建议；支持原文/修改版对比。
- 保存草稿、批改历史与模型反馈；估分为模拟参考，不能称为官方评分。
### 3. 个人薄弱项与复习
- 按词汇理解、长难句、逻辑推断、选项陷阱、语法、表达等类别记录错因。
- 展示可追溯的真实练习记录、薄弱项趋势，并提供下一次练习入口。
- 允许用户修正 AI 错误归因；不得把生成式推断当作客观统计事实。
## 技术约束与既有成果
- Android：Kotlin + Jetpack Compose + Room / SQLite，个人本地优先，不强制云同步。
- 保留在 vivo V2359A / Android 16 上验证通过的 Sign in with ChatGPT OAuth 及 Responses API 现有实现，不进行无根据重构。
- 用户报告已经完成一次端到端请求：授权、获取 7 个可见模型、HTTP 200、SSE `response.completed`；覆盖安装后凭证可恢复。测试不代表所有账号或所有时间永久可用。
- 将 Token 继续存放在 Android Keystore 保护的本地安全存储。避免日志、崩溃报告或导出文件泄露凭证。
- AI 不可用时，已有材料、题目、作答历史和错题仍可离线使用；AI 讲解明确显示需要网络。
- 原文、真题、例句、音频和配图必须具备合法使用来源；不抓取商业应用私有资源。
## 当时停止或暂缓的范围（现非永久限制）
- 暂停扩充独立六级词书、FSRS 调度精调、TTS 发音改善、图片背词和单词打卡系统。

## 执行路线
1. **G3-P0｜审计与保全**：盘点当前功能、数据库版本、登录凭证、测试基线；建立升级前备份和迁移验证，不清数据、不撤销授权。
2. **G3-P1｜阅读闭环**：导入材料 → 做题 → 判题 → AI 解析 → 错因记录 → 再练；先把一篇阅读完整做通。
3. **G3-P2｜写作/翻译闭环**：输入 → 逐句批改 → 修改 → 保存历史 → 回顾重复错误。
4. **G3-P3｜个人化与体验**：薄弱项看板、练习任务推荐、离线降级、异常提示、备份/恢复、界面一致性。
5. **体验改进**：按需实际使用，交付 APK 与已知限制；不设七天准入门槛。

## 2026-10-18 阅读 AI 诊断修订（优先于固定四层提示）

用户明确指出通用逐步提示过于机械：主要需求是 AI 通读当前篇章，结合本人所选错项解释可能的误读，并说明如何从题干关键词与同义替换回到原文证据，找到真正支持答案的内容。

- 核对后以逐题「AI 分析我的作答」为主入口，不要求先经过四层。发送当前篇章全文、本篇题目与作答，以及当前题有来源的参考和可核对证据；不发送另一篇章或全部历史。
- 分析应解释文章结构、当前错项的具体误读、题干到段落/证据句到正确选项的对应关系，并支持补充当时理解与继续追问。不能仅凭选项断言用户真实想法；未答题、无来源参考、证据不足和参考键冲突需明确说明。
- AI 引用进行本地字面匹配，提供原文所在段落并突出引用；匹配不代表语义解释一定正确。未匹配引文提示核实，不补造来源。
- 固定四层内容改为默认收起的本地线索与参考。旧讲解保留。只有完整 AI 响应才按题保存；失败保留旧分析，错因仍由用户确认，不自动请求或连续重试。
