## 未解决的实质性问题

1. **试卷资料校对**：2023 扫描资料与 3 月合并卷题序、2024-06 第 1 套 O) 标签、跨网站套次对应、参考译文/范文及原文证据逐句核验尚未完成。不得以自动推断代替来源证据。
2. **资料状态与可用性**：10 套待校对资料是否已补齐，需要按最新内容包实际核对；不能从“目录存在”推定能核对答案。
3. **特殊场景质量**：大字体/TalkBack、长题干与窄屏、真实 Token 到期刷新/429/断网等场景尚无全面实测结论。按实际改动风险选择测试，不作为所有任务的前置门槛。
4. **编辑持久性与交互**：历史记录显示“已保存”前立刻强杀进程可能丢最后一笔编辑；界面计时器不承诺跨进程持续。若改进相关功能，须重新验证并准确说明。
5. **已知脚本问题**：旧 UI 自动化滚动/点击脚本曾不稳定，手动 ADB 验证与隔离测试不能被推断为脚本已修复。
