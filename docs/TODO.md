## 2026-10-21 0.7.0-desk：写译特化与 AI 交互重构

- 导航改为 写作 / 翻译 / 阅读 / 我的；每个练习进入全屏工作台，返回键逐层回退。题库导入导出、备份、单词与旧版功能移到「我的」下的独立页面，原功能保留。
- 写作工作台：给定开头句识别与一键插入、字数目标（从题目要求读取）、30 分钟计时、构思提纲（只给角度和提纲，不代写）。提交前提示字数不足；提交后锁定原稿，修改另存为修改稿，可在各稿之间切换并与上一稿逐词对照。
- 批改改为逐行 JSON 协议：模拟档位（参照公开的 15 分制五档描述，标明仅供参考）、切题 / 内容 / 结构 / 语言四项、逐处问题。问题按原文字面定位，以红笔（必改）/ 赭色（可改）下划线画在原稿上；点画线处逐条采纳或忽略，自动跳到下一条；用采纳的修改一键生成修改稿。模型未按协议输出时退回 Markdown 原文显示，不做猜测解析。
- 翻译工作台：中文原文按句编号（修复 PDF 换行），点句子可问难词或句子骨架（不直接给整句译文）。批改按句对照：每句的对应译文、准确 / 基本准确 / 有误 / 漏译、建议译法（默认折叠）、重点词语。
- 阅读：答题卡保留五格和连续输入，新增一次输入 10 个字母自动接到第二篇、填满一篇自动跳到下一篇；核对后自动选中第一道错题。「讲解这题」输出定位句、同义替换对照、逐项选项分析、可能的误读和自测；「在原文中看」跳到原文并高亮该句。原文页按 PDF 换行重排段落并编号，点任意一段可翻译、拆解长句或看段意，可整篇梳理结构。旧四层本地提示和错因笔记保留。
- 追问：作文、翻译、每道阅读题、每个段落、每个翻译句子都有独立的对话；快捷问题点一下即按原文发送。回复流式显示，可随时停止（停止会关闭网络连接）；只有完整回复才与问题一起保存，失败时显示没发出的问题和「重试」。
- 数据：新增 coach_turns 表保存讲解与对话，Room v7→v8 只新增表和索引；对话不改写练习行，生成期间仍可编辑。备份升级为 JSON v5（含对话，引用必须指向备份内的练习），继续导入 v1—v4。界面颜色收敛为纸与墨，红 / 赭 / 绿只用于批注语义。
- 已验证：103 项单元测试（含新增协议解析、文本定位、段落与分句、逐词对照、连续输入拆分）、Lint 0 错误 / 7 项既有警告、AndroidTest APK 构建；模拟器完整隔离仪器测试通过（v1—v7 迁移到 v8、v5 备份往返与 v1—v4 导入，此次在最后一轮界面修改前运行）。模拟器用标注为布局样本的非 AI 数据检查了作文、翻译批改页面。
