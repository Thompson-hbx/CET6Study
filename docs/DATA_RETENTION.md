# 私人资料保留与归档规则

2026-10-24 只读统计：当前受版本控制文件合计 523,218,596 字节（约 499 MiB / 523 MB）。其中 `.tools` 273,579,775、`raw-papers` 225,521,422、`test-evidence` 22,468,462 字节。未统计忽略的构建缓存与新未跟踪文件；数字是本次盘点快照。

原卷、来源映射、校对证据、学习数据库及 WAL/SHM 配套快照均保留。归档前先制作两份独立副本，核对文件清单、大小和 SHA-256，并从其中一份实际预览/恢复验证；凭证目录不纳入收集。仅有“复制完成”或 Git 推送记录不能证明独立备份可恢复。

建议新增长期资料时按考次、来源和修订归档；设备升级前及重要训练完成后保留完整 ZIP，另存原卷。日常快照按日保留最近一月，再评估按周/月保留；每次数据迁移前后的快照、原始资料和关键问题证据长期保留。这是人工筛选建议，不是自动删除规则。

历史 APK、重复截图、临时 OCR、运行日志可列为归档候选，先标明是否可重建、是否包含独有校对证据、是否已具备两份独立备份，再由用户确认具体删除范围。数据库快照必须作为一个一致的数据库/WAL/SHM 组处理。未经确认不移除任何已有历史文件；本轮没有删除、压缩重写或移动私人资料，也没有修改 Git 历史。
